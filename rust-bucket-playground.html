Reference

Every word in the language

specDeclare a value. Specs are what a car is.
shiftChange a value you already declared.
honkPrint to the output.
check … swerveIf / else. Chain with swerve check.
lap i from 1 to 5Counted loop. Both ends included.
cruiseKeep going while a condition holds.
brakeLeave the loop now.
build name(a, b)Define a function.
deliverReturn a value from a build.
green / redTrue / false. Traffic lights.
stalledNo value at all.
[1, 2, 3]A convoy. Index from zero: gears[0].
and or notLogic, spelled out.
+ - * / % ^Maths. ^ is power.
round(x, n)Round to n decimals.
sqrt / cbrtSquare and cube roots.
abs / floorMagnitude, round down.
min / maxSmaller, larger.
len(convoy)How many items.
add(convoy, x)Append to a convoy.
text(x)Turn a number into words.

The design rule was that a keyword only earns its place if the car meaning explains the code meaning. shift changes what gear you're in. lap is a counted trip round a circuit, which is exactly a for-loop. brake stops you early. swerve is what you do when the road ahead is blocked. Nothing is themed for the sake of it — spec and build would read fine in a real language.

Reference / OBD-II

Talking to the car

Every car sold in the US since 1996, and in Europe since 2001 (petrol) or 2004 (diesel), has an OBD-II port under the dash. These commands read it. In this playground the cars are simulated, each with its own fault. Pick one with plug.

PSystem. P powertrain, B body, C chassis, U network.
0Who defined it. 0 generic, same on every car. 1 manufacturer-specific.
3Subsystem. 3 is ignition and misfire. 4 is emissions, 7 is transmission.
01The fault. Here, cylinder 1. So P0301 reads as “cylinder 1 misfire.”
plug "commuter"Connect to a car on the lift.
scan()Stored trouble codes. OBD mode 03.
pending()Codes seen once, not yet confirmed. Mode 07.
clear()Erase codes, lamp off. Mode 04. Returns how many.
mil()Is the check engine light on?
vin() / vehicle()VIN (mode 09) and a readable name.
wait(seconds)Let simulated time pass. Engines warm up; faults return.
sensor("rpm")A live reading. Mode 01. Accepts a PID too: sensor("0C").
sensors()Every sensor name.
unit("coolant")The unit, for honking.
explain("P0420")What a code means. Unknown codes still get decoded by structure.
causes("P0420")Common causes, most likely first.
pad(x, width)Pad text so columns line up.
rpm · 0CEngine speed, rpm
coolant · 05Coolant temp, °C
stft · ltftShort / long fuel trim, %
maf · 10Airflow, g/s
o2 · 14Upstream O2 sensor, V
load · throttleEngine load, throttle, %
alsospeed, intake, timing, voltage, fuel
"clean"2016 Mazda MX-5. Nothing wrong. Your baseline.
"commuter"2011 Honda Accord. Running lean, tired catalytic converter, small EVAP leak pending.
"misfire"2008 Subaru WRX. Cylinder 3 is misfiring. Rough idle.
"overheat"2005 Ford F-150. Starts clean. Codes appear as it heats up.
"cold"2012 Toyota Corolla. Thermostat stuck open, never reaches temperature.
